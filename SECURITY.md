# Безпека Ord 2

## Головне: де лежать ключі API
- У репозиторії й на сайті **немає жодного ключа API**. Це статичний сайт: серверного коду, який міг би зберігати чужі ключі, тут немає.
- Кожен користувач вводить **власні** ключі в Налаштуваннях. Вони зберігаються лише в його браузері: зашифровані паролем (AES-GCM 256, ключ із пароля через PBKDF2-SHA256, 310 000 ітерацій) у `localStorage`, або в `sessionStorage` до закриття вкладки. Відкритого тексту на диску немає.
- Ключі не потрапляють у стан застосунку, експорт JSON, пакети обміну чи спільний контент. Запити до ШІ йдуть напряму з браузера до провайдера (`fetch` з `referrerPolicy: no-referrer`, без cookies).
- Не вписуй ключі у код, у README чи в issue. Це публічний репозиторій.

## Обмеження, які треба розуміти
- Усі сторінки на `vasyl-www.github.io` ділять один origin і один `localStorage`. Тому ключі лише зашифровані; не залишай їх відкритим текстом ніде.
- Захист паролем не врятує від шкідливого розширення браузера чи шкідливого коду на цьому ж origin, поки сховище розблоковане. Ставь у кабінеті провайдера **ліміт витрат** і, де є, обмеження прав ключа. Для безкоштовних ключів ризик менший.
- Content-Security-Policy (у `index.html`) дозволяє скрипти лише з цього сайту і запити лише до перелічених API. Не додавай сторонні скрипти й CDN.
- Контент спільноти вважається недовіреним: текст екранується, SVG чиститься й показується лише як картинка, посилання на відео будуються лише як пошук YouTube.

## Спільнота
- Сервера немає, тож чужі ключі та дані ніхто не збирає. Модерація: у загальну добірку потрапляє лише те, що ти закомітив у `community/feed.json`. Імпортовані пакети проходять ту саму очистку (текст екранується, SVG чиститься, невідомі провайдери відкидаються).
