# Ord 2: норвезька для себе

Статичний вебзастосунок (GitHub Pages): історії A1/A2, картки SM-2, перекладач, форум з ШІ-персонажами, практика (диктант, шедоїнг, мінімальні пари), профіль із порогом читання, спільний контент, вхід через Google.
Попередній застосунок «Ord-kort» збережено в [`legacy/ord-kort/`](legacy/ord-kort/index.html).

## Що працює без нічого
Історії, картки, практика, профіль, вбудований набір у «Спільнота». Прогрес лежить у `localStorage` браузера (копія файлом: Профіль → Налаштування → Експорт).

## Ключі ШІ (Claude, GPT, Gemini, DeepSeek, OpenRouter)
Профіль → Налаштування → Ключі ШІ. Спершу створи пароль сховища, потім додай ключі. Деталі й обмеження: [SECURITY.md](SECURITY.md).
- Ключі лишаються в браузері, зашифровані паролем. Вони не йдуть у репозиторій, хмару чи спільний контент.
- Режим «Авто»: спершу платні ключі, при збої наступні, потім безкоштовні. Прапорець «Безкоштовний рівень» ставиш сам: від нього залежить, у яку вкладку «Спільноти» потрапить згенероване.
- Кожен пост, переклад і історія від ШІ підписані: провайдер, модель, платний чи безкоштовний.
- Назви моделей у полі «Модель» змінюються з часом. Якщо провайдер повертає помилку, онови назву за кабінетом провайдера.

## Вхід через Google і спільнота (Firebase, безкоштовний рівень Spark)
Без цього кроку застосунок працює, але без входу й хмарного контенту.
1. [console.firebase.google.com](https://console.firebase.google.com) → створи проєкт → додай **Web app** → скопіюй `apiKey`, `authDomain`, `projectId`, `appId` у `js/firebase-config.js` (це публічні ідентифікатори, не секрети).
2. **Authentication** → Sign-in method → увімкни **Google**. Settings → **Authorized domains** → додай `vasyl-www.github.io`.
3. **Firestore Database** → створи базу в режимі production → вкладка Rules → встав вміст `firestore.rules` → Publish. Indexes → додай індекси з `firestore.indexes.json` (або `firebase deploy --only firestore`). Без індексів застосунок працює, але сортування робить сам.
4. У Google Cloud Console → Credentials → обмеж Browser key за HTTP-реферером `https://vasyl-www.github.io/*`. Увімкни App Check.
5. `npm install && npm run build` (збирає `js/cloud.bundle.js`), закоміть і запуш.

Що зберігається в Firestore: `content` (поширений ШІ-контент з підписом моделі, без імені), `reports` (скарги, читаєш лише в консолі), `users/{uid}` (твій прогрес, бачиш лише ти).

## Розробка
```
npm install
node tools/serve.js        # http://127.0.0.1:8099
npx playwright install chromium && npm test
```
Структура: `js/` модулі застосунку, `src/cloud.js` Firebase (збирається в `js/cloud.bundle.js`), `firestore.rules`, `sw.js`, `manifest.json`.

## Відомі обмеження
Тексти, факти, жарти й переклади пише ШІ; носієм не перевірені. Оцінка вимови: збіг розпізнаного тексту, не фонетика. Меми й зображення від ШІ: прості SVG, не копії реальних мемів. Відео: лише посилання на пошук YouTube. OCR у веб-версії вимкнено: він потребував би сторонніх CDN, а це послабило б захист ключів.
