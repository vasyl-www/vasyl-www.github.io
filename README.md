# Ord 2: норвезька для себе

Статичний вебзастосунок (GitHub Pages): історії A1/A2, картки SM-2, перекладач, форум з ШІ-персонажами, практика (диктант, шедоїнг, мінімальні пари), профіль із порогом читання, спільний контент, обмін контентом файлами.
Попередній застосунок «Ord-kort» збережено в [`legacy/ord-kort/`](legacy/ord-kort/index.html).

## Що працює без нічого
Історії, картки, практика, профіль, вбудований набір у «Спільнота». Прогрес лежить у `localStorage` браузера (копія файлом: Профіль → Налаштування → Експорт).

## Ключі ШІ (Claude, GPT, Gemini, DeepSeek, OpenRouter)
Профіль → Налаштування → Ключі ШІ. Спершу створи пароль сховища, потім додай ключі. Деталі й обмеження: [SECURITY.md](SECURITY.md).
- Ключі лишаються в браузері, зашифровані паролем. Вони не йдуть у репозиторій чи спільний контент.
- Режим «Авто»: спершу платні ключі, при збої наступні, потім безкоштовні. Прапорець «Безкоштовний рівень» ставиш сам: від нього залежить, у яку вкладку «Спільноти» потрапить згенероване.
- Кожен пост, переклад і історія від ШІ підписані: провайдер, модель, платний чи безкоштовний.
- Назви моделей у полі «Модель» змінюються з часом. Якщо провайдер повертає помилку, онови назву за кабінетом провайдера.

## Спільнота без сервера
Жодного бекенду, Firebase чи акаунтів: сайт статичний.
- **Профіль** (ім'я), прогрес і ключі ШІ лишаються в браузері. Між пристроями прогрес переноситься файлом (Профіль → «Профіль і обмін»).
- **Спільнота**: вбудований набір, добірка адміна й імпортовані пакети. Вкладки «Платні ШІ» / «Безкоштовні ШІ» та підпис моделі лишились.
- **Обмін**: «Мої матеріали у файл» → надіслати людині (чат, пошта) → вона «Імпортує пакет». Чужі записи очищаються так само, як і раніше.
- **Добірка для всіх**: додай записи в `community/feed.json` (поле `items`, формат як у пакеті, але `provider`, `model`, `tier` обов'язкові), закоміть, і їх побачать усі. Так ти модеруєш контент: тільки те, що потрапило в репозиторій.
- Побачити користувачів чи їхні ключі неможливо: сервера немає.

## Ігри, теми, ШІ-віконце, нагадування
- **Ігри**: швидка пара (комбо), падаючі слова, Ordle дня, меморі. Слова з твоїх карток; помилки можна додати у словник.
- **Теми**: темна, світла, авто (кнопка в меню й у Налаштуваннях). **Звук** натискань вимикається в «Звукові ефекти».
- **ШІ-віконце**: кнопка 🤖, раз на день саме з'являється з привітанням і полем питання. Потрібен ключ ШІ.
- **Нагадування**: локальні сповіщення (Налаштування). Справжній push без сервера неможливий.

## Піни
Вкладка «Піни»: свої фото, GIF, відео, нотатки й посилання (зберігаються лише в браузері, IndexedDB) і пошук у Wikimedia Commons та Openverse без ключів. Автор і ліцензія показуються в картці. Адреси пошуку відкриті в CSP лише для цих хостів.

**Стрічка ШІ** (Піни → «Стрічка ШІ»): 10–30 пінів на день (повзунок). ШІ пише факти, фрази, жарти, малює прості SVG, а фото й GIF підбираються з відкритих джерел за його запитом. Кожен пін підписаний моделлю; вкладки «Платні / Безкоштовні / Вбудовані». Генерація йде раз на день при відкритті стрічки (до 3 запитів до твого ключа), без ключа додаються вбудовані піни зі слів.

## Переклад будь-де, реакції на піни, мови інтерфейсу
- **Швидкий переклад:** кнопка 🌐 (ліворуч унизу) і спливаюча кнопка при виділенні тексту. Кожен переклад іде в історію й автоматично стає піном (вкладка Піни → Мої → «Переклади»), з підписом моделі.
- **Реакції на піни:** 👍 / 👎, коментарі; після коментаря ШІ відповідає (потрібен ключ). Кожна реакція й коментар зберігають автора (`uid` і ім'я), тож у майбутньому (пакети обміну чи сервер) різних користувачів можна розрізняти.
- **Мови інтерфейсу:** українська й норвезька (кнопка «Мова» в меню або Налаштування). Переклад інтерфейсу йде словником у `js/i18n.js`; вміст для вивчення (слова, історії, переклади слів) не чіпається, невідомі рядки лишаються українськими.

## Розробка
```
node tools/serve.js        # http://127.0.0.1:8099
npx playwright install chromium && npm test
```
Структура: `js/` модулі застосунку, `js/cloud.js` спільнота без сервера, `community/feed.json` добірка, `sw.js`, `manifest.json`.

## Відомі обмеження
Тексти, факти, жарти й переклади пише ШІ; носієм не перевірені. Оцінка вимови: збіг розпізнаного тексту, не фонетика. Меми й зображення від ШІ: прості SVG, не копії реальних мемів. Відео: лише посилання на пошук YouTube. OCR у веб-версії вимкнено: він потребував би сторонніх CDN, а це послабило б захист ключів.

## Синхронізація між пристроями («акаунт» = твій приватний репозиторій)

Без сервера: прогрес, картки, піни, форум-нотатки, рекорди ігор синхронізуються через **твій власний приватний репозиторій GitHub** (файл `ord-sync.json`, стиснутий).

Одноразове налаштування:
1. Створи **приватний** репозиторій (напр. `ord-data`), порожній.
2. GitHub → Settings → Developer settings → Fine-grained tokens → доступ лише до цього репозиторію, право **Contents: Read and write**.
3. Профіль → «Синхронізація» → встав `власник/назва` і токен → «Підключити». На другому пристрої зроби те саме з тим самим репозиторієм.

Що синхронізується: прогрес вивчення, власні слова, історія, піни (текстові/посилання/AI/переклади) із реакціями й коментарями, ігри, форум. Не синхронізується: **ключі ШІ** (ніколи), налаштування пристрою, завантажені власні файли (blob).
Злиття: новіша картка перемагає, журнали й коментарі об’єднуються, XP/рекорди — максимум, видалення пінів поширюються (надгробки). Обмеження: видалені теми форуму/переклади можуть «воскреснути» з іншого пристрою.
